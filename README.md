# Treeline

A maze-building tower defence on the open steppe. Attackers take the cheapest route across the terrain and learn your kill zones, two waves late.

## Status

Milestone 1: terrain painting and flow-field pathfinding for infantry and vehicles. Open `index.html` in any browser to play.

## Plan

1. Grid, terrain, attackers walking a flow field (done)
2. Obstacles and lagged danger memory
3. Weapons and the full attacker roster
4. Waves, budget, end screens
5. Python balance simulator, then playtests

Everything is tested in the browser first; the finished game ships to iOS, Google Play and web together.
