- 2026-11-06 — [claude] balance — First balance run (`docs/balance/2026-11-06/`, tool `tools/balance/Balance.cs`, runs under Mono in seconds): duels of one defender against a stream of each ground attacker, unopposed crossing times per map, and 60 map runs of five mixed waves, each under both firing rules. - 2026-11-06 — [claude] sim — Threat-aware routes (rules/attackers.json pathfinding, never built before): waves are numbered (`BeginWave`), attackers remember where defenders were seen or fired from, each unit type learns with its `adaptation_lag_waves` delay and memory fades per wave. Route modes Fastest / Evade / Safest per unit type and knowledge. Changed rule (written into rules/attackers.json): a threat zone is where a known defender can hit, inside its range and its own sight (belts and bushes count; the mortar: anywhere a known defender sees), because range alone now covers the whole map. Weapons that do no damage after armour are no threat (rifles do not scare MRAPs). Targeting: a shooter keeps its target while it stays alive, seen and in range (before, damage was spread across a passing column and nothing died). Debug view: each attacker's route drawn by mode (yellow fastest, green evade, violet safest), mode counts in the status line. 4 tests in `RouteTests.cs`.
- 2026-11-06 — [claude] sim — All ground vehicles work: carriers (IFV, MRAP, van) let their troops out when badly hit, troops inside die with the vehicle and add their line damage if it gets across; destroyed carriers with troops inside or unloading blast attacking troops within `blast_radius_m`; destroyed vehicles leave a `wreck` (hides, gives cover, blocks vehicles, routes rebuilt); `tree_move_cost` lets tanks push through groves and belts; mortar shots splash over `blast_radius_m`. `NavGrid` now takes move costs from the obstacles table (terrain and objects; before, rocks and wire did not affect movement). Data: rock blocked / blocked, wreck 3 / blocked, bush 1.5 / 1 (Sheets and CSV; proposals). Per-unit stats for balance runs. Debug view: buttons for all five ground defenders, waves Infantry / Armour / Transport / Mixed, budget 3000, unloading carriers in yellow. 6 tests in `VehicleTests.cs` (43 pass under Mono; debug view type-checked against Unity stubs; not yet run in Unity).

- 2026-11-05 — [claude] sim — Minimal battle (Yaroslav: set up a minimal fight and start testing pathfinding and balance). `Battle` now runs a whole round: `QueueWave(unit, count, delay, interval)` spawns attackers at a random reachable top-edge cell (seeded, repeatable); they follow the flow field to the rear edge at their `speed_mps`, slowed by terrain; each one that gets across adds its `line_damage` to the line (`LineHealth` default 20, a placeholder). Both sides shoot with shared vision (any friendly unit that sees an enemy counts, via `VisionMap.SeeChance`, refreshed every 0.25 s). Damage is expected value per step, no dice: `dps x accuracy x seen chance x armour factor (armour.csv) x cover (obstacle cover_acc x cover_dmg for the shooter class; `VisionMap.CoverFor`) x hill `on_cover_mult`, x `move_accuracy_mult` when firing on the move`; range x the shooter's `on_range_mult`; nearest visible target in range. Defenders fire only while standing; air_defence hits only aircraft, anti_tank only vehicles. Outcome Won / Lost / Ongoing. New `ArmourTable`, extra `UnitDef` fields (damage type, armour, dps, accuracy, fire-on-move, line damage). Debug view: attackers drawn (red infantry, orange vehicles), buttons Start 10 recruits / 8 regulars / mixed, Speed x4, round readout. 8 new EditMode tests in `CombatTests.cs` (30 pass under Mono, not yet run in Unity). Not done: aircraft and drones, carriers dismounting, mortar splash, attackers reacting to the defence (threat-aware routes), attackers stopping to fight, refunds, placement zone. All unit numbers are still proposals, so the first balance runs will mostly show what to change.
- 2026-11-05 — [claude] sim — Defender deployment (Yaroslav): `Battle` in `Treeline.Sim`. Preparation phase: placing and moving defenders is instant. Once the round starts, a newly placed or moved defender appears at the bottom edge (the entry cell with the shortest way to its spot) and runs there at 3x the speed of a regular soldier (3 x 6 = 18 m/s), over the real terrain, slowed by rivers, belts and wire; it cannot fire while running (nothing fires yet). Placing costs the unit's `build_cost` from the budget, moving is free (my assumption). Refused: unknown unit, attacker, not enough budget, outside the field, impassable ground, or no way in from the bottom edge. Also `UnitTable` (reads `units.csv`), `FlowField.To` (routes to one cell) and 7 EditMode tests in `BattleTests.cs` (22 tests pass under Mono, not yet run in Unity). Debug view: buttons Battle on/off, Deploy gunner / rifles at the red cursor, Start round, Move last here. Not done: firing, attackers reacting, a placement zone, defenders being hit while running.
