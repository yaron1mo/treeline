# Visual audit image sources

2026-11-27. Codex made the A, B, and C concept boards with the built-in OpenAI image model for this issue. The phone images are crops of those boards. These are review images, not production assets.

Prompts requested a top-down steppe battle with pig attackers, a belt, defenders, and one explosion. A requested clean cartoon art. B requested neon pixel art without gore. C requested neon pixel art with stylised blood and fallen pigs. Each prompt requested close-up units and a phone view.

The current images are Unity captures of this repository. The named reference games in the audit are examples for study. This change does not include their assets.
