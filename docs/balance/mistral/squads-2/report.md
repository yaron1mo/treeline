# Mistral squads-2 — helicopter and drone waves, cost band 6000–12000, measured again

Task: issue #57, follow-up of #23 / PR #56 (`docs/balance/mistral/squads/report.md`). Date: 2026-11-28. Decision by Yaroslav (2026-11-28): first better tests, **no game value changed** (`stop.csv`, `units.csv`, `armour.csv`, `waves.csv`, `battle_rules.csv`, Sim code). The deliverable is the measurement and a comparison with PR #56.

## Method

Same method as PR #56:

- Tool: `WaveCost.cs` squad mode (`SQUADS_FILE`), run by the `Balance run` workflow (mono on `ubuntu-latest`, same sources). For each squad the scripted player can buy only the defender types of that squad. `cost` is `NaN` when the squad cannot hold the wave with `max_budget` 12000. Each wave is fought alone on an empty field; the cost is the smallest budget (step 25) that holds the wave on at least 8 of 10 seeds.
- Wave set: `tools/balance/squad_waves.csv` — 85 waves. Waves 1–40 are the unchanged PR #56 set (mixed probe waves, measured cost 500–6000 on Forest belts). Waves 41–85 are new (this task):
  - waves 41–45: helicopter waves with 2 helicopters each (41, 42, 44, 45) and 43 with 2 helicopters + 2 old_tank — 5 waves with 2+ helicopters;
  - waves 46–48: drone-attacker waves (recon_uav spotting + fpv, 4–8 fpv) in the 500–6000 band; waves 49–50: drone waves with one `one_way_drone` each plus a helicopter (air_defence is the only type that can target `one_way_drone`, so a helicopter makes the scripted player buy it);
  - waves 51–85: mixed waves generated by `make_waves.py` (seeds 11 and 23) and tuned locally (WaveCost, no squads, Forest belts) until the measured cost landed in 6500–11500.
  - Cost bands on Forest belts (measured cost of the no-squad run, max_budget 12000): **500–6000: 45 waves** (1–40 + 46–50), **6000–12000: 40 waves** (41–45 + 51–85). The analysis bands by the cost of the squad `all` on Forest belts in the squad runs below.
  - `one_way_drone`: the Sim has it (`fly_to_rear` in `Battle.FlyAircraft`, `units.csv` row exists), so waves 49–50 include it.
- Squads: `make_squads.py` writes every squad of N types from the 9 defence types plus `all`. N = 3, 4, 5 (one Balance run per size). Squad name = short type names joined by `+`.
- Runs (`Balance run` on branch `mistral/squads-2`, `run.json`: waves_file `squad_waves.csv`, squads_file `squads.csv`, max_budget 12000, playtest_seeds 0, fields = the 3 fields of PR #56: Balka and railway, Forest belts, River crossing):

| Run | Slots | Rows | Status |
| --- | --- | --- | --- |
| 46128105705 | 4 | 85 × 127 × 3 = 32385 | see below |
| (s3 run) | 3 | 85 × 85 × 3 = 21675 | see below |
| (s5 run) | 5 | 85 × 127 × 3 = 32385 | see below |

- Analysis: `analyze.py` (this folder) reads the merged `wave-cost.csv` of each run and writes per size, field and band: held share, cost premium (median of squad cost / cost of `all` on the waves the squad holds), rank; per defender type: must-have, best-10 share, unused. Dominant = held share ≥ 0.90 and premium ≤ 1.2 (squad `all` excluded from the dominant list here; PR #56 counted it).
- The 2 village fields (Crossroads, Village street) are not fields of PR #56 and are out of scope of this task.
