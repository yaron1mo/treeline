# Map attribution

All `real-*.json` fields in `unity/Assets/Resources/Fields/` are made from
OpenStreetMap vector data.

**Map data © OpenStreetMap contributors, ODbL**
(https://www.openstreetmap.org/copyright)

The data is available under the Open Database License (ODbL) 1.0
(https://opendatacommons.org/licenses/odbl/1-0/). The raw Overpass API answers
used to build the maps are cached in `tools/maps/cache/` and carry the same
licence. The conversion scripts are in `tools/maps/`.

The game shows the credit "Map data © OpenStreetMap contributors" in the credits.
